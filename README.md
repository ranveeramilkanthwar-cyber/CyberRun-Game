# 🏃 CyberRun 3D - Fall Guys Physics Runner

## 🎮 Overview
CyberRun 3D is a fast-paced 3D multiplayer-style obstacle course runner inspired by Fall Guys, built with Three.js and Cannon-es.

## ✨ Key Features
- **True Flat Unified Elevation**: All ramps, bridges, and tracks are calibrated to a seamless level.
- **Dynamic Sweeper Arms**: Rotating neon hazard beams with authentic physics bounce.
- **Swinging Pendulum Hammers**: Heavy physics-driven obstacle pendulums.
- **Bouncy Launch Pads**: Springboards that launch players across hazard zones.
